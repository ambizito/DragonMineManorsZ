# DragonMineManorsZ 0.1.26.9.3

Atualização do cliente e do servidor para Minecraft 1.20.1, Forge 47.4.10 e
Java 17.

## Principais alterações

- Maestria Global Saiyajin.
- Progressão sequencial do Kaioken, com aviso da forma anterior pendente.
- Balanceamento atualizado das transformações e raças.
- Controle individual da geração natural dos conjuntos de Esferas do Dragão.
- Configurações de proteção de terreno, spawn, teleporte, Waystones e dimensões
  no pacote de servidor.
- Pacote de atualização do cliente com JAR e configurações sincronizados.

## Arquivos da release

- `dragonminez-2.1.3.jar`: mod modificado, obrigatório no cliente e servidor.
- `DragonMineManorsZ-client-0.1.26.9.3.zip`: atualização dos jogadores.
- `DragonMineManorsZ-server-0.1.26.9.3.zip`: pacote completo do servidor.
- `SHA256SUMS-0.1.26.9.3.txt`: hashes para conferir os downloads.

Leia `README-CLIENTE.md` ou `servedata/README-SERVIDOR.md` antes de instalar.
