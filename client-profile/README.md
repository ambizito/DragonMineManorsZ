# Metadados do perfil usado no desenvolvimento

`minecraftinstance.json` é a cópia integral do arquivo local modificado nesta
versão: `isUnlocked` foi alterado para `true` para permitir gerenciamento de
conteúdo e preservar o JAR personalizado no CurseForge.

Este arquivo contém os caminhos, identificador e lista de mods do perfil
`D:\CurseForge\Instances\Dragon Mine Z`. É um registro da instalação; não o
copie sobre o perfil de outro jogador. O instalador modifica apenas o campo
necessário no perfil de destino e guarda uma cópia anterior em `mod-backups`.
