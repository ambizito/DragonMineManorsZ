Raga Balls - installed by Villager Replacer

This pack registers the seven Raga Balls with DragonMineZ so they appear in
the DMZ Blocks menu and in the external dragonballs system. Their actual
spawning is controlled by Villager Replacer: land only, one per planet.

The first launch creates these files. Restart Minecraft once after the
folder first appears so DragonMineZ can register the external ball set.
